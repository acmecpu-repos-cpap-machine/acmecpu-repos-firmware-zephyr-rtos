openocd commands for debugging
--------------------------------------------------------------------------------------------------------------------------
- First export the environment using the command above, then run the openocd commands
- The openocd tool has to be kept running in the terminal for gdb to be able to work from command line or eclipse

# command for custom board (tested on C201)
